# Deep Learning study books and notes
## Deep Learning Study Books and Notes

This repository is a personal library of books, lecture notes resources for studying deep learning and machine learning.  It collects foundational mathematics, neural network theory, hands‑on tutorials, and materials to prepare for deep learning study.
